# ひがやいびん

2号店オープン準備のための「やること」ページ。

## 今できること（第1段階：ページと保存）

- やることの追加・編集・完了・削除（内容 / 必要な対応 / 誰に任せるか / 期限）
- 期限の近い順に表示。期限切れ・今日・3日以内は色で目立たせる
- 完了した項目は下にまとめて薄く表示
- スマホとパソコンの両方の画面幅に対応

## 保存について（大事）

今は **開いた端末のブラウザの中** に保存しています（localStorage）。
スマホとパソコンの間ではまだ同期されません。ログインもまだありません。
`store.js` だけを差し替えれば、Supabase などの共有の保存先に切り替えられる作りにしてあります。

## 開き方

ビルドは不要です。`index.html` をブラウザで開くか、次のように配信します。

```
python3 -m http.server 8000   # → http://localhost:8000
```

## テスト

```
node --test
```

## ファイル

| ファイル | 役割 |
| --- | --- |
| `index.html` / `style.css` | 画面 |
| `app.js` | 画面の動き |
| `logic.js` | 並べ替え・期限の判定（テストあり） |
| `store.js` | 保存（ここを差し替えると保存先が変わる） |
