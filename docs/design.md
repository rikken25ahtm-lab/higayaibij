# ひがやいびん 設計メモ（Claude Code 用）

## 1. 目的
居酒屋オーナーのダイくんが、2号店の準備を一人で抱え込まないように助ける個人秘書システム。
まずは「2号店オープンの準備」に特化する。結婚式は後で別プロジェクトとして追加する。

## 2. 使う人
- 主な利用者：ダイくん（オーナー）
- 画面はスマホとパソコンの両方で使えること
- 業者とのやりとりは電話が中心。声で入力できることを重視する

## 3. 今の試作（参考）
claude.ai上の「2号店 やること」ページが試作版。
項目は「内容・必要な対応・誰に任せるか・期限」の4つ。フラットな一覧で、完了の切り替えと削除ができる。
この形を基準に、Claude Codeで本格的に作り直す。

## 4. 画面（一番大事）
- ひとつのページで、今やるべきことが一目でわかること
- 「やること」は何も区切らないフラットな一覧
- 上部に入力フォーム（内容 / 必要な対応 / 誰に任せるか / 期限）
- 期限は近い順に並べる。期限切れ・今日・3日以内は目立たせる
- 完了した項目は下にまとめるか、取り消し線で薄く表示する
- 音声入力ボタン（対応している環境のみ表示）

## 5. 入力
- 第1段階：画面から手で、または声で入力する
- 第2段階：メールの内容から候補を作る（ダイくんが確認してから追加）
- 電話の内容の取り込みは、今回は対象外（後で検討）

## 6. 報告（通知）
- 朝10時：前日17時〜当日10時の間に起きたこと（追加・期限の変更・届いたメールの要点など）
- 夕方17時：当日10時〜17時の間に起きたこと
- 報告はスマホに通知が届く形にする。通知を押すとページの該当部分が開く
- 報告が届いても、やることの追加や変更はダイくんが決める

## 7. 添付書類（請求書・領収書など）
- 添付は、Googleドライブの決まったフォルダに保存する
- やることの項目に、ドライブのリンクを紐づけて表示する
- 金額などのお金の情報が含まれるため、フォルダの共有範囲はダイくんと必要な人だけにする

## 8. 直近の優先順位の表示
- 項目に「直近／中期／最後」のどれかを付けられるようにする
- 直近の項目は、ページの一番上に出す
- 最初は手で振り分け、必要になったら自動の振り分けを検討する

## 9. データ
- 項目は1件ずつ保存する（内容・必要な対応・担当・期限・状態・優先度・作成日時・更新日時・添付リンク）
- 試作の17件の項目は、最初の準備には使わない（ダイくんのリストは、システムができてから少しずつ追加する）

## 10. 段階（作る順番）
1. **ページと保存**：項目の追加・編集・完了・削除。スマホとパソコンで開ける
2. **音声入力**：声で項目を追加できる
3. **報告の通知**：朝10時・夕方17時に、前日の内容をまとめて通知する
4. **メールとドライブの連携**：メールの候補を出し、添付をドライブに保存してリンクをつける
5. **結婚式**：別のプロジェクトとして、同じ仕組みを使って追加する

## 11. 注意点
- 送信・支払い・契約など、取り消せない操作は必ずダイくんの確認を挟む
- 個人情報・お金の情報（請求書など）は、ログインしたダイくんだけが見られるようにする
- 電話の録音は、事前に相手に伝える

## 12. Claude Code での最初の作業（案）
- 「ページと保存」の段階から始める
- 技術は、スマホで開けるWebページ＋簡単なデータ保存（例：Supabaseなど）を候補にする
- 最初の画面は、上の「4. 画面」の内容だけを作る
